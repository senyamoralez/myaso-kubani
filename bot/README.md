# Бот заказов и личный кабинет «Мясо Кубани и стейки»

Сервер принимает заказы с сайта и присылает их в рабочий чат сотрудников в Telegram. Сотрудники ведут заказ кнопками: оплата получена, в работе, взвешено, передан курьеру, доставлен. Покупатель получает статус каждого шага в Telegram.

## Как это работает

1. Покупатель оформляет заказ на сайте. Сервер сам пересчитывает цены по каталогу: подменить цену в браузере нельзя.
2. В рабочем чате появляется сообщение с заказом и кнопками **«Оплата получена»** и **«Отменить заказ»**.
3. Покупатель платит по QR-коду СБП и нажимает «Я оплатил». В чат приходит напоминание проверить поступление.
4. Сотрудник видит деньги в банке и нажимает **«Оплата получена»**. Дальше идут шаги **«Взять в работу»**, **«Ввести сумму после взвешивания»** (бот просит ответить числом), **«Передан курьеру»** или **«Выдан покупателю»**, **«Доставлен»**.
5. Под заказом копится история: кто и во сколько нажал каждую кнопку.
6. Если после взвешивания сумма меньше оплаченной, бот пишет, сколько вернуть покупателю.

Команды в рабочем чате:
- `/orders` — открытые заказы;
- `/today` — итоги дня (бот сам присылает их в 21:00);
- `/id` — показать ID чата.


## Личный кабинет покупателя

**Вход без пароля, по коду из Telegram.**
1. Покупатель вводит номер телефона на сайте.
2. Первый раз сайт открывает бота лавки, и покупатель нажимает «Поделиться номером». Telegram передаёт номер, привязанный к аккаунту, и подделать его нельзя. Если номер в Telegram не совпадает с введённым на сайте, вход не выполняется.
3. Дальше при каждом входе бот присылает 6-значный код. Код действует 5 минут. После 5 неверных попыток он блокируется, а запросить код на один номер можно не чаще 5 раз в час.
4. Сессия хранится в защищённой cookie (HttpOnly): скрипты на странице её не видят. В разделе «Безопасность» есть кнопка «Выйти на всех устройствах».
5. Если подключить SMS (переменные `SMS_*`), код для покупателей, которые ещё не подтверждали номер в Telegram, придёт по SMS.

**Бонусы:**
- 300 бонусов за регистрацию;
- кешбэк по уровням: Choice 3%, Prime 5% от 20 000 ₽ покупок, Вагю A5 7% от 60 000 ₽;
- 1 000 бонусов в день рождения: дату покупатель указывает в профиле один раз;
- бонусами можно оплатить до 30% заказа;
- кешбэк начисляется, когда сотрудник нажимает «Доставлен» или «Выдан». Если заказ отменён, списанные бонусы возвращаются.

Все суммы и уровни настраиваются в `.env`.

**В кабинете:** карта покупателя с уровнем и балансом, история заказов с кнопкой «Повторить», история бонусов, адреса доставки, профиль с пожеланиями мяснику и список устройств. При оформлении заказа имя, телефон, адрес и пожелания подставляются сами.

**Для сотрудников:** команда `/client +79001234567` в рабочем чате показывает уровень, бонусы и покупки клиента.

**Важно для работы входа:** сервер должен быть на поддомене сайта (сайт `myaso-kubani.ru`, сервер `api.myaso-kubani.ru`) и работать по HTTPS. В `ALLOWED_ORIGIN` впишите точный адрес сайта, например `https://myaso-kubani.ru`.

## Что нужно один раз настроить

### 1. Создать бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя, например «Мясо Кубани · Заказы», и адрес, например `myaso_kubani_bot`.
3. BotFather пришлёт **токен**. Его нельзя никому показывать.

### 2. Создать рабочий чат
1. Создайте группу в Telegram, например «Лавка · Заказы», и добавьте туда сотрудников и бота.
2. Отправьте в группу команду `/id`. Бот ответит номером вида `-1001234567890`.

### 3. QR-код для оплаты
В приложении банка для бизнеса (счёт ИП или ООО) создайте статический QR-код СБП. Сохраните его картинкой `pay-qr.png` рядом с `server.js`.

### 4. Сервер
Подойдёт любой недорогой VPS с **Ubuntu 24.04** (Timeweb Cloud, Selectel, Beget и т. п.). Нужен Node.js версии 18 или новее: в Ubuntu 24.04 он ставится из стандартного репозитория. Проверить можно командой `node -v`.

```bash
# на сервере
sudo apt update && sudo apt install -y nodejs caddy
sudo mkdir -p /opt/lavka-bot && sudo chown $USER /opt/lavka-bot
# скопируйте сюда содержимое папки bot (например через scp или FileZilla)
cd /opt/lavka-bot
cp .env.example .env
nano .env            # впишите BOT_TOKEN, STAFF_CHAT_ID и адрес сайта в ALLOWED_ORIGIN
node server.js       # проверка: должно написать «Бот: @...» и «API слушает порт 8080»
```

Чтобы бот работал постоянно и сам перезапускался:

```bash
sudo cp deploy/lavka-bot.service /etc/systemd/system/
sudo chown -R www-data /opt/lavka-bot
sudo systemctl enable --now lavka-bot
sudo journalctl -u lavka-bot -f    # смотреть логи
```

HTTPS: заведите поддомен `api.ваш-домен.ru` на IP сервера, впишите его в `deploy/Caddyfile`, скопируйте файл в `/etc/caddy/Caddyfile` и выполните `sudo systemctl reload caddy`. Сертификат Caddy получит сам.

### 5. Подключить сайт
В `index.html` найдите строку

```html
<script>window.SHOP_API="";</script>
```

и впишите адрес сервера: `window.SHOP_API="https://api.ваш-домен.ru";`. Если оставить пусто, сайт работает в демо-режиме и заказы никуда не отправляет.

## Если меняются цены или товары
Цены берутся из `catalog.json`: это тот же каталог, что и на сайте. После изменения каталога сайта замените `catalog.json` и перезапустите бота: `sudo systemctl restart lavka-bot`.

## Где хранятся заказы
В файле `data/orders.json`. Его стоит раз в день копировать в надёжное место. Когда заказов станет много, хранилище можно перевести на базу данных.

## Проверка без Telegram
`npm test` запускает имитацию Telegram и проводит заказ по всем шагам. `node test/account.js` проверяет вход, бонусы и защиту кабинета.
