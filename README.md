# Мясо Кубани и стейки

Сайт мясной лавки с каталогом, оплатой по QR-коду СБП, личным кабинетом покупателя и Telegram-ботом для сотрудников.

## Что внутри

| Папка | Что это |
| --- | --- |
| `site/` | Готовый сайт: `index.html` и фото. Можно выложить на любой хостинг как есть |
| `bot/` | Сервер заказов, личный кабинет и Telegram-бот. Node.js 18+, без зависимостей. Инструкция — `bot/README.md` |
| `tools/` | Исходники сайта и скрипты сборки |

## Как устроен сайт

- 8 разделов каталога: мясо, стейки, сыры, молочка, итальянские сыры, колбаса, рыба и икра, полуфабрикаты.
- Корзина и полная оплата по QR-коду СБП.
- Личный кабинет: вход по коду из Telegram, бонусы, уровни, история заказов.
- Без сервера (`window.SHOP_API=""` в `site/index.html`) сайт работает в демо-режиме: заказы и кабинет хранятся в браузере, код входа — 123456.
- С сервером: впишите его адрес в `window.SHOP_API`, и заказы пойдут в Telegram сотрудникам.

## Как пересобрать сайт после правок

Нужен Python 3 и Pillow.

```bash
python3 tools/assemble.py     # собирает tools/page.html из исходников
python3 tools/make_index.py   # оборачивает в site/index.html
```

- Тексты и разметка главной — `tools/base.html`.
- Стили — `tools/cat.css`, `tools/account.css`.
- Логика — `tools/head.js`, `tools/account.js`, `tools/tail.js`.
- Каталог (товары, цены, фото) — `tools/catalog.json`. Его же копия лежит в `bot/catalog.json`: при смене цен обновите обе.

`tools/build_catalog.py` пересобирает каталог из фото поставщиков. Исходные архивы в репозиторий не входят.
